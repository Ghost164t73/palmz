PALMZ STORE DEMO
=================

Open index.html in a browser.

Important:
1. Replace WHATSAPP_NUMBER in index.html with the real PALMZ WhatsApp number.
2. Replace the demo products/prices in the products array with the real PALMZ catalogue.
3. The current checkout opens WhatsApp with the customer details + cart summary.
4. Paystack and registered accounts are intentionally NOT included yet; the frontend structure can be extended later.
